# Formula Growth Audit

**Live → https://eddieatadapty.github.io/formula-flow-rebuild/**

Five ideas to turn more Formula users into subscribers, each built into a clickable version of Formula's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Turn the paywall into their plan | +10–20% CR to purchase |
| 02 | Ask at the first plan, customize after the purchase | +10–15% CR to purchase |
| 03 | Ask which diet, then build the plan around it | +5–15% CR to purchase |
| 04 | Formula’s own proof while the plan builds | +5–10% CR to purchase |
| 05 | A 3-month offer that reaches their date | +5–10% ARPU |

Every price, rating and feature comes from Formula's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Formula. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
